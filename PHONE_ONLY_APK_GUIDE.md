# Scan Master V1 — Build an APK using just your Android phone

**Important:** This is an installable *starter app* with the Stage B Kotlin calculation engine. It does NOT yet fetch Angel One prices, scan stocks, emit live triggers, or validate indicator outputs against TradingView. The screen explicitly shows **NOT CONNECTED**; it never invents prices or signals. Bias+ and Bias− code is preserved in the engine but intentionally omitted from the screen until verified.

## One-time GitHub setup (phone web browser)
1. Create or sign into a GitHub account at https://github.com .
2. Tap **+** > **New repository**. Name it `ScanMasterV1`. Set **Private** if preferred. Tap **Create repository**.
3. On the repository page, tap **uploading an existing file** (or **Add file > Upload files**). **GitHub website does not directly import a ZIP as a project**. Unzip the provided ZIP using the phone's Files app or a ZIP extractor, then upload the *contents* of the `ScanMasterV1` folder, keeping the `app`, `engine`, `tools`, `.github` folders and their subfolders. Some mobile browsers do not support uploading directories/hidden `.github` folder. In that case choose desktop site and use a GitHub-compatible Git client, or use the alternate one-tap importer described below.
4. Confirm the repository shows `.github/workflows/build-apk.yml` and `app/build.gradle.kts`. Without these, GitHub cannot build this APK.

## Build and download
1. Open your repository on GitHub in Chrome.
2. Tap **Actions**. Allow workflows if GitHub asks.
3. Tap **Build Android APK** > **Run workflow** > the green **Run workflow** button.
4. Open the newest workflow run. It should have a green check. If red, the build failed — do not expect an APK; share the failure log.
5. Scroll to **Artifacts** and download `ScanMasterV1-debug-apk` (a ZIP).
6. Open Downloads with Files and extract this ZIP to get `app-debug.apk`.
7. Tap `app-debug.apk`. If asked, allow *Install unknown apps* for the Files/browser app, then install. Disable that permission again afterward if desired.
8. Open **Scan Master V1**. It correctly says **NOT CONNECTED**, because live market-data integration is not yet built.

## Updates
After each project code update is uploaded to GitHub, repeat the build process and install the new APK. For Android to install it as an update (without uninstalling), it must have the same app ID and signing key; GitHub's autogenerated debug signing keys may change across runners. If an update fails due to a signature mismatch, uninstall the old starter app first (there is currently no saved user data). A future production version needs persistent release signing, securely managed.

## Notes
- Do **not** upload Angel One PIN, password, TOTP seed, API secret, or access token into GitHub code or commit history.
- This project contains no Gradle wrapper; GitHub Actions installs Gradle 8.10.2 automatically.
- The APK build has not been exercised on GitHub from this environment. Only local Kotlin compiler checks can be claimed here.
